# Website v2 Preview Branch

This branch is a non-live preview of the HushStrike Studio v2 storefront.

- `master` remains the live GitHub Pages source.
- Pack #001 uses the existing public asset files as a migration bridge.
- The preview removes unsupported claims such as animated VTT tokens.
- Future product pages are intended to be generated from canonical product data in the private `HushStrike/hushstrike-studio` repository.
- Do not merge this branch until the preview has been reviewed and explicitly approved.
